Unitree A1 Robotics Simulation Control Showcase

A sanitized, runnable demo repository for explaining a Unitree A1 simulation-control analysis pipeline. All metrics, logs, and figures are synthetic demo artifacts.

Pipeline

1. Synthetic logs
Generate deterministic 600-step Unitree A1 demo CSV files.
2. Parser
Validate required fields and model naming.
3. Metrics
Compute tracking, base-height, MPC, force, contact, and cost summaries.
4. Figures
Create demo plots for interview discussion.

Run

pip install -r requirements.txt
python scripts/run_demo_pipeline.py
pytest

Boundary

This repository is not the original non-public project. It contains no real robot telemetry, no protected source code, no checkpoints, and no hardware validation claim.
