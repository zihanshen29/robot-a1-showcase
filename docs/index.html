这个页面展示什么

合成日志
生成 600 step 的 Unitree A1 demo CSV，用于展示数据接口和状态字段设计。
解析与校验
对 CSV 字段做 schema 检查，缺字段时给出清晰错误。
指标计算
计算前向位移、速度跟踪误差、姿态、支撑力、接触占空比、MPC accept/reject 和 cost trend。
可视化
生成面试可讲的 demo/synthetic 图表，不包含真实私有实验数据。
