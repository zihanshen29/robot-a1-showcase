# Limitations and Ethics

This repository is a sanitized demo showcase. It should not be read as a claim that a real Unitree A1 was deployed, that long-horizon locomotion is solved, or that a door task was completed.

## Boundaries

- All CSV logs are synthetic.
- All metrics are demo metrics derived from synthetic data.
- All figures are demo figures.
- The simplified simulator is not a real dynamics model.
- The MPC-style fields are diagnostics for the public demo pipeline, not evidence of a production solver.
- Long-horizon robustness, real robot validation, and door-task transfer are outside the implemented scope.

## Publication Principles

- Do not publish raw logs from non-public work.
- Do not claim real hardware performance unless it is independently reviewable.
- Do not include collaborator, advisor, institution-internal, or machine-specific context.
- Do not present generated code as original source code from a protected project.
- Do keep the pipeline runnable, inspectable, and clearly labeled.
