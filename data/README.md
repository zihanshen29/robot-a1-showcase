# Data

This folder contains synthetic, sanitized Unitree A1 demo CSV logs generated by `scripts/generate_sample_data.py`.

The files under `sample_logs/` are not real robot logs and are not copied from a simulator run. They use deterministic pseudo-random variation to support parser tests, metric calculations, and demo figures.

Expected fields include 600-step state, velocity, MPC-style diagnostics, predicted support-force values, and contact indicators. See `src/a1_showcase/config.py` for the complete schema.
